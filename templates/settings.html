{{ icon('server', 14) }}sonarr (optional)

cross-checks season/episode counts against your sonarr library, and powers the calendar's upcoming-episodes panel.

when a show is promoted, finishes, is removed, or has its vault path edited or repaired, sonarr is told the new folder so it keeps finding the show. it only changes the path - nothing is renamed, moved or re-downloaded - and every change is recorded in history.

one per line: unbinge's folder = the same folder as sonarr sees it.

{{ icon('calendar', 14) }}calendar feed

subscribe in google/apple/outlook calendar to see your drip schedule (and sonarr's upcoming air dates, if configured) update automatically.

google calendar: settings → add calendar → from url. refreshes every 12-24 hours, not instantly.

this url has no password - anyone with it can see your schedule.

if unbinge isn't reachable from outside your network (e.g. a localhost or LAN-only address), google can't fetch the url above at all - it'll silently never update. download a snapshot instead and import it by hand: google calendar → settings → import & export → import. do this again whenever your schedule changes meaningfully (monthly is usually plenty).
